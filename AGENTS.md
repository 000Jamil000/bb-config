# Личные доработки BB

Этот репозиторий — источник восстановления личной конфигурации BB. Сохраняй здесь
каждую установку, удаление, включение, отключение и доработку плагина, а также
изменение настроек BB. Это относится и к сторонним плагинам: Needs You имеет ID
`inbox`, Handoff — `handoff`, отдельная кнопка к нему — `handoff-button`.
Сторонние плагины сохраняй установленными из каталога, чтобы получать обновления.
Для дополнительных кнопок предпочитай маленький отдельный плагин, который
открывает существующий экран оригинала. Не дублируй его формы своим попапом.
Не создавай форк ради UI-кнопки без отдельного согласования.

После изменения работающего BB:

1. Проверь установленный путь и источник через `bb plugin list --json`.
2. Обнови приватный снимок `.local/config/`: `python3 scripts/snapshot.py --settings-only`.
3. Для своей доработки сохрани исходники в `plugins/<id>/`. Установленную версию
   на сервере и checkout на другой машине нельзя считать автоматически синхронизированными.
4. Обнови `docs/customizations.md`: что изменено, зачем, где работает и как
   восстановить. Если добавлен новый вид настройки, дополни restore.py или явно
   опиши ручной шаг. Не оставляй сохранённый JSON без способа применения.
5. Проверь `python3 scripts/snapshot.py --check` и diff. Не объявляй сохранение
   завершённым, если изменение осталось только в работающем BB. Коммит и push
   делай в рамках поручения пользователя; незакоммиченные изменения не скрывай.

`scripts/restore.py` показывает план, `--plugins --apply` устанавливает плагины
и применяет поддерживаемые настройки. Порядок восстановления и ограничения —
в `docs/customizations.md`. `scripts/setup_tracking.py --apply` включает
напоминание для всех проектов BB и Git-хук проверки снимка.

Не коммить секреты, авторизации, базы, переписки и вложения. Снимок исключает
секретные поля схемы, но свободный текст и исходники тоже проверяй перед коммитом.
Не читай и не меняй базу BB напрямую: используй штатные API/SDK/CLI.
Изменения маршрута Claude и тесты с изменением его IP требуют отдельного явного
поручения. Сохранение настроек не является таким поручением.

`scripts/snapshot.py` без `--settings-only` копирует установленную версию плагинов.
Не запускай его поверх незакоммиченных исходников. Текущий путь установки всегда перепроверяй через CLI. Изменение локального файла ещё не обновляет плагин на другой машине.

Эти инструкции общие: BB читает `.bb/AGENTS.md` (ссылку на этот файл), Codex CLI —
корневой `AGENTS.md`, Claude Code — импорт из `CLAUDE.md`. Меняй правила здесь.

## Публичный код и личная конфигурация

`config/` содержит только обезличенные настройки и примеры. Снимок действующей
установки записывается исключительно в игнорируемую `.local/config/`.
`restore.py` объединяет словари по верхнему уровню; локальные значения имеют
приоритет, списки заменяются целиком. Вложенные объекты переопределяй целиком.
Не переноси адреса серверов, машин, прокси, идентификаторы и личные инструкции
в публичные файлы. Личные инструкции и старые документы хранятся в `.local/docs/`.
Секреты и авторизации в снимок не включаются даже локально.
Перед коммитом: `python3 scripts/privacy_check.py --staged`.
Перед публикацией: `python3 scripts/privacy_check.py --history`.
Личную часть сохраняй зашифрованно через `scripts/private_backup.py`;
GitHub её не восстанавливает. Снимок конфигурации не заменяет бэкап BB.
