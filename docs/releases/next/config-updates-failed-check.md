На сервере с установленным Config Updates шаг обновляет плагин до 0.1.4.
После успешной проверки без новых релизов последующая ошибка в командах
`check` и `status` выводит причину и возвращает код 1. При потере checkout
сообщение подсказывает, как привязать плагин к постоянной рабочей копии.

Проверка шага сверяет версию, источник и состояние плагина. Регрессионный
тест в `plugins/config-updates` проверяет обе команды при сбое. Для отката
повторите установку плагина из предыдущего стабильного релиза.
