Выполняется на сервере BB. Зависимостей нет.

Плагин открывает файлы не только на Mac, но и на Windows-компьютере (приложение по
умолчанию для типа файла). Файл, который уже лежит на этом компьютере, открывается на месте
без копии. Название в списке плагинов — Open on Desktop; ID и ключ настройки `macHostId`
прежние. Выбор машины при пустой настройке: единственный подключённый Mac, как раньше;
без Mac — единственный Windows-компьютер.

Уже применено, если установлен `file-local-open` 0.2.0 из этого checkout; если плагин не
установлен, шаг неприменим. Настройка `macHostId` сохраняется.
Проверка: значки у ссылки на файл в сообщении открывают его и сохраняют в Загрузки; на
установке с Mac поведение не изменилось. Повтор безопасен. Откат — по полю `rollback`.
