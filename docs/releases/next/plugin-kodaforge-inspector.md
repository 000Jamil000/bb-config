На сервере BB с установленным KodaForge можно добавить центральный чат для рабочих пространств диалогов. При первом применении шаг установки инспектора требует согласия пользователя.

1. Установите инспектор шагом релиза с флагом `--install`. Для отдельной установки из checkout используйте [инструкцию плагина](../../../plugins/kodaforge-inspector/README.md).
2. Обновите страницу BB. Откройте обычный диалог, затем вручную перейдите в KodaForge. Убедитесь, что действует штатная раскладка. В настройках инспектора включите центральный чат и проверьте переключение между чатом и файлом, ветку Git и терминал. Для автооткрытия укажите ID диалога и включите отдельный переключатель. Проверьте выбранный и соседний диалоги. Оба переключателя по умолчанию выключены.
3. Выполните `bb kodaforge-inspector status`. Поле `browser` содержит итог и время последней проверки.
4. Для возврата к штатному виду отключите инспектор командой `bb plugin disable kodaforge-inspector` и обновите страницу.
