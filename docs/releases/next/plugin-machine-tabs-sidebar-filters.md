Обновляет Machine Tabs до 0.2.0 на сервере BB, где плагин уже установлен
из каталога релизов. Штатный шаг `local-plugin` проверяет источник и версию,
собирает и перезагружает плагин при необходимости и повторяет проверку.
Для отключённого плагина сохраняется выбор пользователя.

Включите Custom и выберите тему и проект. Введите часть названия треда.
Под полем поиска отображаются число видимых активных тредов и сортировка.
Очистите поиск и верните «Все темы» и «Все проекты», чтобы увидеть весь
список выбранной машины. Повтор и откат описаны в манифесте шага.
