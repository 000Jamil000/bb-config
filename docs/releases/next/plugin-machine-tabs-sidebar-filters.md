Обновляет Machine Tabs до 0.2.0 на сервере BB, где плагин уже установлен
из каталога релизов. Штатный шаг `local-plugin` проверяет источник и версию,
собирает и перезагружает плагин при необходимости и повторяет проверку.
Для отключённого плагина сохраняется выбор пользователя.

Прежний вид списка не меняется: блок Last 5, значки проектов и меню
группировки и сортировки остаются. В режиме Custom нажмите воронку в строке
поиска и выберите тему и проект. Справа появится счётчик «показано из всего»
для выбранной вкладки машины. Крестик возвращает полный список. При первой загрузке списка плагин спросит, какие значки показывать в строках: проектов (как сейчас, отмечено заранее) или тем; выбор хранится в настройке `rowMark`. Повтор и откат
описаны в манифесте шага.
