1. Где: сервер BB. Зависимостей нет.
2. Уже применён, если работающий Machine Tabs установлен из этого checkout,
   имеет версию 0.1.3 (или новее) и статус `running`. Неприменим, если плагин не
   установлен.
3. Применение: `python3 scripts/updates.py run <версия>/plugin-machine-tabs`
   (`npm ci --include=dev`, `bb plugin build`, `bb plugin reload machine-tabs`).
   Если каталог плагина в checkout отличается от релиза, шаг ничего не собирает
   и сообщает об этом: реши с пользователем, что делать с его правками.
4. Меняются `node_modules/`, `dist/` плагина и загруженная версия. Настройки
   плагина, выбранная вкладка машины и настройки списка тредов сохраняются.
   Треды не копируются, не открепляются и не переносятся между проектами.
5. Ожидаемый результат: `status: verified`, в `detail` —
   «machine-tabs 0.1.3 from this checkout». После перезагрузки страницы BB при
   группировке по проектам закреплённый тред виден и в разделе Pinned, и в
   группе своего проекта; дочерний тред другого проекта виден и под родителем,
   и в группе своего проекта. Проект, все треды которого закреплены, не
   приглушён и не уходит в конец списка.
6. Повтор безопасен: при совпадении версии шаг только проверяется.
7. Откат: вернуть каталог плагина к предыдущему релизу, пересобрать и
   перезагрузить плагин. Данные тредов откат не затрагивает.
