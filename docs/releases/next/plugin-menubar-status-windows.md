Выполняется на сервере BB. Зависимостей нет.

Серверная часть принимает путь файла статуса Windows (`C:\…` или `C:/…`). Добавлен клиент
для Windows `plugins/menubar-status/windows/`: полоска на панели задач с состоянием и
числом агентов и та же панель по наведению (клик закрепляет). Клиент macOS не изменился; в помощнике `server.py`
действие «открыть bb» работает на обеих системах.

Уже применено, если установлен `menubar-status` 0.3.0 из этого checkout; если плагин не
установлен, шаг неприменим. Настройки `hostId` и `filePath` сохраняются, на Mac ничего
переустанавливать не нужно.
Клиент Windows ставится отдельно на нужном ПК:
`powershell -ExecutionPolicy Bypass -File plugins/menubar-status/windows/install.ps1`,
затем `hostId` и `filePath` по подсказке установщика. Это ручное действие вне шага.
Проверка: `bb menubar-status show` печатает сводку. Повтор безопасен. Откат — по полю `rollback`.
