Выполняется на сервере BB. Зависимостей нет.

Серверная часть принимает путь файла статуса Windows (`C:\…` или `C:/…`). Добавлен клиент
для Windows `plugins/menubar-status/windows/`: полоска на панели задач, повторяющая заголовок
значка в строке меню macOS (состояния агентов с числами, столбики лимитов 5 часов и недели,
таймер сброса), и та же панель по наведению в собственном окне с WebView2. Клиент macOS не
изменился. В `panel.html` действие «открыть bb» и сообщения странице-хозяину работают на
обеих системах; строки «нет данных» и прочие лимиты показываются только Windows-клиенту.

Уже применено, если установлен `menubar-status` 0.3.1 из этого checkout; если плагин не
установлен, шаг неприменим. Настройки `hostId` и `filePath` сохраняются, на Mac ничего
переустанавливать не нужно.
Клиент Windows ставится отдельно на нужном ПК:
`powershell -ExecutionPolicy Bypass -File plugins/menubar-status/windows/install.ps1`
(скачивает три библиотеки WebView2 SDK из NuGet и сверяет SHA-256), затем `hostId` и
`filePath` по подсказке установщика. Это ручное действие вне шага.
Проверка: `bb menubar-status show` печатает сводку; на Windows-ПК —
`plugins/menubar-status/windows/test-hover.ps1` без ошибок. Повтор безопасен. Откат — по
полю `rollback`.
