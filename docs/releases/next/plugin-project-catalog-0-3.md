Обновление плагина `project-catalog` до 0.3.2.

1. Выполняется на сервере BB. Нужен установленный `project-catalog` (шаг
   `v1.1.0/plugin-project-catalog`); без него шаг неприменим.
2. Уже применено, если `bb plugin list` показывает `project-catalog` версии
   0.3.2 в состоянии `running`.
3. Шаг пересобирает и перезагружает плагин из `plugins/project-catalog`.
4. Данные не теряются: карточки со старым полем одной категории читаются как
   список из одной категории. Группы категорий у пользователя пустые, пока он
   их не задаст во вкладке или командой `bb catalog group`.
5. Проверка: `bb catalog categories` печатает категории; во вкладке «Проекты»
   слева есть фильтр разделов, а в строке проекта при наведении — значки
   тредов, правки и нового треда.
6. Повтор безопасен.
7. Откат — см. поле `rollback`.
