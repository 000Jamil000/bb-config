Необязательный плагин добавляет кнопку «Подключить проект» при создании треда без окружения. Кнопка открывает штатную форму подключения на выбранной машине и сохраняет черновик. Шаг выполняется на сервере BB и не зависит от Project Catalog. Для проверки откройте создание треда на машине без копии проекта. После установки кнопка появляется рядом с недоступной отправкой.
