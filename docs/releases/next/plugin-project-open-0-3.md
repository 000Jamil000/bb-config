Обновление установленного Project Open на сервере BB до 0.3.0.

Соберите плагин и перезагрузите его. Проверьте версию и состояние running в `bb plugin list`. Откройте меню «…» в строке треда с окружением и проверьте команды папки и терминала. Через Customize actions можно добавить их в строку. Настройка быстрых действий пользователя сохраняется при обновлении.
