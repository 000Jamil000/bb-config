Обновление установленного Project Open на сервере BB до 0.3.0.

Поведение по умолчанию прежнее: кнопки папки и терминала появляются в строке
треда при наведении. Новая настройка плагина `placement` со значением `menu`
переносит их в штатное меню «…» треда; через Customize actions отдельные
действия можно закрепить в строке. Настройки пользователя, включая
`rowActions`, при обновлении сохраняются.

Проверьте версию и состояние running в `bb plugin list`. Наведите курсор на
строку треда с окружением: кнопки папки и терминала на месте. При желании
выполните `bb plugin config project-open set placement menu` и откройте меню «…».
