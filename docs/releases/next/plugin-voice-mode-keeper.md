Keeper 0.2.2 проверяет закреплённый форк Voice Mode по версии и хешам и не
накладывает уже встроенные правки. Каталоговый путь сохраняет прежние проверки
совместимости. Остальные плагины остаются под защитой Keeper. Шаг
voice-mode-personal-fork отдельно проверяет миграцию источника; версия Keeper
сама по себе не считается установкой форка.
