Project Logo 0.2.1 выбирает источник на машине текущего треда для обоих
инструментов и CLI из треда. Недоступный основной источник на другой машине
не мешает работе. При отсутствии источника на текущей машине запись запрещена.

Где: сервер BB; дополнительных зависимостей от шагов нет. Требования плагина
сохраняются. Проверка: версия 0.2.1 из checkout, running или пользовательское
отключение; отсутствующий плагин неприменим.
Применение и проверка: `python3 scripts/updates.py run next/project-logo-thread-host --development`
у автора; после публикации — `run <release>/project-logo-thread-host`.
Обработчик local-plugin проверяет состояние, собирает и перезагружает плагин
при необходимости. Ожидается verified. Повтор сохраняет существующие иконки.
Проверка поведения: status в треде возвращает машину этого треда, даже когда
основной источник находится на отключённой машине.
Откат: восстановить предыдущие исходники, npm ci, bb plugin build и
bb plugin reload project-logo. Файлы значков сохраняются.
