# v1.0.3 — Config Updates: экран нового треда, автопринятие, значок по необходимости

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Кнопка «Обновить до … с ИИ» открывает штатный экран нового треда BB: задание
  вписано, выбраны проект checkout и машина сервера. Провайдера, модель и права
  вы видите и выбираете сами, затем отправляете сообщение.
- Релиз, которому на вашей установке нечего делать (все шаги уже выполнены или
  неприменимы), принимается при проверке без агента. Ничего не собирается и не
  устанавливается. Отключается настройкой плагина.
- Значок плагина стоит в нижнем ряду боковой панели, только пока есть
  обновление, остаток шагов или идущий запуск; иначе он в меню «…» того же ряда.
- После полностью применённого релиза архивируется тред, который вёл обновление
  по журналу, в том числе запущенный с экрана нового треда.
- Скрипт обновления сверяет версию плагина с закреплённым коммитом и не собирает
  плагин, если его каталог в checkout отличается от релиза.
- Исправление `v1.0.1`: из его манифеста убран ошибочно попавший шаг
  `plugin-project-logo`. Тег не перемещался.
- Несовместимых изменений нет.

## Кому применять

- Тем, у кого установлен Config Updates из checkout этого репозитория. Если
  плагин не установлен, шаг неприменим. Скрипт и документация приходят вместе с
  закреплённым коммитом и шага не требуют.
- Требования прежние: BB 0.49+, Node.js 22+, npm. Только сервер BB.

## Шаги

### `plugin-config-updates` — Собрать и перезагрузить Config Updates 0.1.3

1. Где: сервер BB. Зависимостей нет.
2. Уже применён, если работающий Config Updates установлен из этого checkout,
   имеет версию 0.1.3 (или новее) и статус `running`. Неприменим, если плагин не
   установлен.
3. Применение: `python3 scripts/updates.py run v1.0.3/plugin-config-updates`
   (`npm ci --include=dev`, `bb plugin build`, `bb plugin reload config-updates`).
   Если каталог плагина в checkout отличается от релиза, шаг ничего не собирает
   и сообщает об этом: реши с пользователем, что делать с его правками.
4. Меняются `node_modules/`, `dist/` плагина и загруженная версия. Настройки
   плагина, журнал и сохранённый результат проверки сохраняются.
5. Ожидаемый результат: `status: verified`, в `detail` —
   «config-updates 0.1.3 from this checkout». После перезагрузки страницы BB
   кнопка «Обновить до … с ИИ» открывает экран нового треда с готовым заданием,
   а значок без доступных обновлений убран в меню «…» нижнего ряда.
6. Повтор безопасен. Плагин перезагружается во время обновления, которое идёт в
   треде агента: тред продолжает работу, журнал не затрагивается.
7. При ошибке сборки продолжает работать прежняя версия; откат — вернуть каталог
   плагина к `v1.0.1` и пересобрать.

## Проверка релиза

- Установка автора (сервер BB на Linux, BB 0.49): плагин 0.1.3 собран и
  перезагружен шагом в режиме разработки; в браузере проверены экран нового
  треда с заданием, проектом и машиной и карточка; значок убран в меню «…» при
  отсутствии обновлений.
- Автопринятие, архивирование по журналу, сверка с закреплённым коммитом и
  сборка релиза из ожидающих шагов проверены автоматическими тестами
  (`npm test` плагина, `scripts/test_updates.py`). На живой установке
  автопринятие впервые сработает на этом релизе у автора.
- Не проверялось: сервер BB на macOS и Windows, установка другого пользователя.
