# v1.0.5 — Machine Tabs: закреплённые и дочерние треды в группах своих проектов

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- При группировке по проектам закреплённый тред вместе со своими дочерними
  виден и в разделе Pinned, и в группе своего проекта.
- Дочерний тред, принадлежащий другому проекту, виден и под родителем, и в
  группе своего проекта.
- Проект, все треды которого закреплены, больше не считается пустым: он не
  приглушён и не уходит в конец списка.
- Обе строки открывают один и тот же тред; треды не копируются и не
  переносятся. Дополнительную строку в группе проекта нельзя перетащить —
  перетаскивается исходная.
- Проверено при включённой настройке Show empty projects; при выключенной BB
  может не показать группу проекта, в которой нет собственных строк.
- Несовместимых изменений нет.

## Кому применять

- Тем, у кого установлен Machine Tabs из checkout этого репозитория. Если
  плагин не установлен, шаг неприменим.
- Требования прежние: BB 0.49+, Node.js 22+, npm. Только сервер BB.

## Шаги

### `plugin-machine-tabs` — Machine Tabs 0.1.3: закреплённые и дочерние треды в группах своих проектов

1. Где: сервер BB. Зависимостей нет.
2. Уже применён, если работающий Machine Tabs установлен из этого checkout,
   имеет версию 0.1.3 (или новее) и статус `running`. Неприменим, если плагин не
   установлен.
3. Применение: `python3 scripts/updates.py run v1.0.5/plugin-machine-tabs`
   (`npm ci --include=dev`, `bb plugin build`, `bb plugin reload machine-tabs`).
   Если каталог плагина в checkout отличается от релиза, шаг ничего не собирает
   и сообщает об этом: реши с пользователем, что делать с его правками.
4. Меняются `node_modules/`, `dist/` плагина и загруженная версия. Настройки
   плагина, выбранная вкладка машины и настройки списка тредов сохраняются.
   Треды не копируются, не открепляются и не переносятся между проектами.
5. Ожидаемый результат: `status: verified`, в `detail` —
   «machine-tabs 0.1.3 from this checkout». После перезагрузки страницы BB при
   группировке по проектам закреплённый тред виден и в разделе Pinned, и в
   группе своего проекта; дочерний тред другого проекта виден и под родителем,
   и в группе своего проекта. Проект, все треды которого закреплены, не
   приглушён и не уходит в конец списка.
6. Повтор безопасен: при совпадении версии шаг только проверяется.
7. Откат: вернуть каталог плагина к предыдущему релизу, пересобрать и
   перезагрузить плагин. Данные тредов откат не затрагивает.

## Проверка релиза

- Валидация манифеста и все Python-тесты scripts из чистого клона коммита релиза.
- Тесты Machine Tabs (10), TypeScript и сборка плагина.
- Живой интерфейс BB: закреплённый тред найден в боковой панели дважды, один
  раз внутри группы своего проекта; группа не приглушена.
- Проверка приватности истории Git; сопоставление изменений с шагом релиза.
- Меню действий на дополнительной строке вручную не прокликивалось.
