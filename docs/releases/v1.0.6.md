# v1.0.6 — Open on Mac 0.1.1: сохранение прямо в Загрузки

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Кнопка «↓» у ссылок на файлы в Open on Mac сохраняет файл прямо в
  `~/Downloads/`, а не во вложенную папку `~/Downloads/BB Files/open-*/`.
- Сохранённый файл сразу выделяется в Finder.
- При совпадении имени новый файл получает имя как в Finder (`имя (2).pdf`);
  существующие файлы не перезаписываются.
- HTML с картинками и стилями сохраняется в отдельную папку `~/Downloads/<имя>/`,
  чтобы относительные ссылки продолжали работать.
- Кнопка «открыть на Mac» работает как раньше. Несовместимых изменений нет.

## Кому применять

- Тем, у кого установлен Open on Mac (`file-local-open`) из checkout этого
  репозитория. Если плагин не установлен, шаг неприменим.
- Требования прежние: BB 0.49+, Node.js 22+, npm, подключённый Mac.

## Шаги

### `plugin-file-local-open-save-downloads` — Open on Mac 0.1.1: «Сохранить» кладёт файл прямо в Загрузки

Кнопка «↓» (сохранить на Mac) у ссылок на файлы раньше клала копию во
вложенную папку `~/Downloads/BB Files/open-*/`, и её было трудно найти.
Теперь файл сохраняется прямо в `~/Downloads/` и показывается в Finder.

1. Выполняется на сервере BB. Зависит только от установленного `file-local-open`.
2. Уже применено, если `bb plugin list` показывает `file-local-open@0.1.1`
   в состоянии `running`.
3. Шаг собирает и переустанавливает плагин из `plugins/file-local-open`;
   модуль для Mac обновляется вместе с ним. Настройка `macHostId` сохраняется.
4. При совпадении имени файл получает имя как в Finder: `имя (2).ext`, старый
   не перезаписывается. HTML с ресурсами сохраняется в папку `~/Downloads/<имя>/`.
   Кнопка «открыть на Mac» по-прежнему использует `~/Downloads/BB Files/open-*/`.
5. Проверка: нажать «↓» у ссылки на PDF — файл появляется прямо в `~/Downloads/`,
   Finder выделяет его.
6. Повтор безопасен: установка идемпотентна.
7. Откат: установить версию 0.1.0 из предыдущего релиза; сохранённые файлы остаются.

## Проверка релиза

- Валидация манифеста и все Python-тесты scripts из чистого клона коммита релиза.
- Тесты Open on Mac (6, из них 2 новых на сохранение), TypeScript и сборка плагина.
- Живая проверка на подключённом Mac: PDF сохранён прямо в `~/Downloads/`,
  повторное сохранение дало `имя (2).pdf`.
- Проверка приватности истории Git; сопоставление изменений с шагом релиза.
