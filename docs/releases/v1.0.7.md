# v1.0.7 — Voice Mode сохраняет источник при восстановлении

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

При чистом восстановлении BB устанавливает Voice Mode из форка, в том числе по старому снимку, где сохранилась ссылка на каталог. При обновлении BB проверяет уже установленный Voice Mode. Совместимая версия остаётся на месте, а пользователи без Voice Mode пропускают этот шаг.

В документацию добавлены инструкции по установке, восстановлению и обновлению Image Gen для пользователей с доступом к его репозиторию.

## Шаги

### `voice-mode-restore-source` — Voice Mode сохраняет канал форка при восстановлении

При новой установке из публичного манифеста или старого снимка с источником форка восстановление выбирает Git-канал форка. На сервере с установленным Voice Mode шаг проверяет источник и версию через `switch_to_fork.py --check`. Отсутствующий компонент пропускается.

Если установлен каталоговый Voice Mode или прежний закреплённый форк, `switch_to_fork.py --apply` выполняет миграцию и проверяет настройки. Переустановка завершает активные голосовые сеансы. Настроенный секрет или неизвестный источник останавливает миграцию до удаления. На совместимом форке повторная проверка завершается без переустановки.

Для восстановления прежнего источника используйте приватный журнал `.local/plugin-patches/voice-mode/fork-migration.json`: проверьте наличие секретов, восстановите записанный источник, настройки и состояние включения. При сбое после регистрации проверьте настройки по журналу перед повтором.

## Проверка релиза

Из чистого клона выполните `python3 scripts/updates.py validate v1.0.7` и `python3 -m unittest discover -s scripts`. На сервере с установленным Voice Mode команда `python3 plugins/voice-mode/switch_to_fork.py --check` подтверждает канал форка.
