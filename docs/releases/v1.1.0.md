# v1.1.0 — Каталог проектов и подключение проекта на машине

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Project Catalog добавляет вкладку «Проекты» с поиском, карточками и состоянием рабочих копий на подключённых машинах.
- Project Machine Setup добавляет кнопку «Подключить проект» рядом с отправкой нового треда, когда для выбранной машины нужно настроить окружение.
- При обновлении существующей установки каждый из новых плагинов можно выбрать отдельно. Снимок настроек и восстановление теперь пропускают самостоятельно устанавливаемый Telegram-плагин `telegram-projects`.

## Шаги

### `externally-managed-plugin-scope` — Исключение отдельно устанавливаемых плагинов из снимка и восстановления

Новая политика вступает в силу вместе со скриптами закреплённого checkout. Snapshot пропускает telegram-projects, restore пропускает его даже при наличии в старом манифесте. Установка плагина и рабочие настройки сохраняются. Проверка использует временный снимок. При ошибке проверьте целостность файлов релиза и повторите шаг.

### `plugin-project-catalog` — Project Catalog 0.2.0: вкладка «Проекты», bb catalog и состояние копий на машинах

Новый необязательный плагин `project-catalog`: вкладка «Проекты» с карточками,
поиском и категориями, команда `bb catalog` и проверка состояния папок проекта
на машинах.

1. Выполняется на сервере BB. От других шагов не зависит. Значки проектов
   берутся из Machine Tabs, если он установлен; без него показывается буква.
2. Уже применено, если `bb plugin list` показывает `project-catalog` версии
   0.2.0 в состоянии `running`, а `bb catalog list` печатает проекты.
3. Шаг собирает и устанавливает плагин из `plugins/project-catalog`. Модуль
   для машин ставится вместе с плагином и запускается на каждой подключённой
   машине при проверке копий. Путей и ID подставлять не нужно: плагин читает
   проекты и машины через BB.
4. Плагин создаёт только собственные данные в хранилище BB (карточки, итоги
   проверок). Папки проектов он читает и не меняет: не выполняет fetch, commit,
   копирование и удаление. Карточки у нового пользователя пустые; они
   заполняются агентом в первом треде проекта или вручную во вкладке.
5. Проверка: `bb catalog sync --refresh` завершается без ошибки и выводит
   список проектов, требующих внимания, либо «Все проверенные копии в порядке».
   Вкладка открывается по адресу `/plugins/project-catalog/projects`.
6. Повтор безопасен на любом этапе: установка идемпотентна.
7. Откат: `bb plugin uninstall project-catalog`. Перед удалением сохраните резервную копию BB для восстановления карточек.

### `plugin-project-machine-setup` — Подключение проекта на выбранной машине

Необязательный плагин добавляет кнопку «Подключить проект» при создании треда без окружения. Кнопка открывает штатную форму подключения на выбранной машине и сохраняет черновик. Шаг выполняется на сервере BB и не зависит от Project Catalog. Для проверки откройте создание треда на машине без копии проекта. После установки кнопка появляется рядом с недоступной отправкой.

## Проверка релиза

Проверьте манифест через `python3 scripts/updates.py validate v1.1.0`. Тесты репозитория запускаются командой `python3 -m unittest discover -s scripts`, тесты каждого плагина — командой `npm test` в его каталоге после `npm ci --include=dev`.
