# v1.2.1 — Machine Tabs 0.2.1: удобные фильтры и поиск в любом алфавите

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- Machine Tabs 0.2.1: фильтры «Тема» и «Проект» открывают собственный список с поиском, числом тредов у каждого варианта и прокруткой — по длинному списку проектов больше не нужно листать системное меню.
- Поиск тредов и поиск в списках фильтров находят название в любом алфавите: «маруся» находит `marusya`.
- Кнопка-воронка в поле поиска видна только при наведении или при включённом фильтре; строка фильтров, открытая без выбора, закрывается сама.

## Шаги

### `plugin-machine-tabs-filter-pickers` — Machine Tabs 0.2.1 — фильтры темы и проекта со своим списком и поиском

Обновляет Machine Tabs до 0.2.1 на сервере BB, где плагин уже установлен.
Штатный шаг `local-plugin` проверяет источник и версию, собирает и
перезагружает плагин при необходимости и повторяет проверку.

Фильтры «Тема» и «Проект» под поиском открывают собственный список вместо
системного: в нём есть строка поиска (при восьми и более вариантах), число
тредов у каждого варианта и прокрутка внутри боковой панели. Кнопка-воронка в
поле поиска видна при наведении на поле и пока включён фильтр. Поиск тредов и
поиск в списках фильтров находят название в любом алфавите: «маруся» находит
`marusya`.

Проверка: в режиме Custom наведите курсор на поле поиска, нажмите воронку,
откройте «Все проекты», наберите часть названия и нажмите Enter. Список тредов
сузится, справа появится счётчик «показано из всего».

## Проверка релиза

Проверьте манифест через `python3 scripts/updates.py validate v1.2.1`. Тесты Machine Tabs: `node --experimental-strip-types --test tests/*.test.mjs` в каталоге плагина после `npm ci --include=dev`; проверка типов — `npx tsc --noEmit`.

Перед публикацией прошли 18 тестов и проверка типов Machine Tabs, тесты скриптов репозитория и проверка приватности истории. В работающем BB проверены поиск по проектам и тредам, выбор проекта и автозакрытие строки фильтров.
