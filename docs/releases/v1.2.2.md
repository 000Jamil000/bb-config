# v1.2.2 — KodaForge: управление вкладками из контекстного меню

Общий порядок — [docs/updates.md](../updates.md).

## Что изменилось

- В контекстном меню рабочей вкладки KodaForge теперь доступны **Close all**
  и **Close others**. Рядом с вкладками остаётся кнопка `+`.
- При закрытии вкладки оставшиеся редакторы сохраняют загруженное состояние.
  Закрытие областей с несохранёнными правками требует подтверждения.
- Plugin Keeper 0.2.5 сохраняет эти изменения при совместимых обновлениях
  каталожного KodaForge.

## Шаги

### `plugin-keeper-workspace-tabs` — Plugin Keeper 0.2.5 для последовательных патчей вкладок

На сервере BB обновляет установленный Plugin Keeper до 0.2.5.
Keeper распознаёт дополнительный патч на уже исправленной каталоговой версии
KodaForge. Повтор сверяет установленную версию. Для отката восстановить
предыдущую версию Keeper и выполнить bb plugin build и bb plugin reload.

### `kodaforge-workspace-close` — Закрытие рабочих областей KodaForge без повторной загрузки редактора

Для включённого каталогового KodaForge на сервере BB. Keeper проверяет патч
на копии, собирает плагин и перезагружает его. Проверка и повтор выполняются
скриптом scripts/kodaforge_workspace_tabs.py с --check и --apply соответственно.
Правый клик на вкладке открывает Close others и Close all; оставшиеся редакторы
сохраняют загруженное состояние. При несовместимости изучить статус Keeper.
Для отката переустановить каталоговую версию и вернуть предыдущие патчи Keeper.

### `kodaforge-close-all-in-tab-menu` — Close all в контекстном меню вкладки KodaForge

В каталожном KodaForge правый клик по вкладке открывает Close all и Close others.
Рядом с вкладками остаётся кнопка +. Подтверждение при закрытии несохранённых
областей сохраняется.

На сервере BB Plugin Keeper 0.2.5 применяет патч поверх действующих исправлений.
Для проверки запустите `python3 scripts/kodaforge_workspace_tabs.py --check`.
При необходимости повторите со флагом `--apply`. Для отката верните предыдущий
Keeper и примените его патчи после переустановки каталожного KodaForge.

## Проверка релиза

- В чистом клоне проверьте манифест командой `python3 scripts/updates.py validate v1.2.2`.
- Запустите тесты скриптов командой `python3 -m unittest discover -s scripts -p "test_*.py"`
  и тесты Keeper командой `python3 plugins/voice-mode-keeper/test_patch_keeper.py`.
- В BB откройте две рабочие вкладки KodaForge. Проверьте, что команда **Close all**
  доступна по правому клику на вкладке и рядом с `+` отдельной кнопки нет.
