# KodaForge Inspector

После установки обе функции выключены. Диалог открывается в BB, а при ручном входе в KodaForge кнопкой `</>` чат остаётся на своём обычном месте. Инспектор проверяет совместимость редактора при любом сочетании настроек.

## Настройки

Откройте настройки плагина **KodaForge Inspector** в BB. Переключатели работают независимо.

| Настройка | Что изменится при включении |
| --- | --- |
| Показывать чат по центру в редакторе диалога | Переписка и поле ввода занимают центральную вкладку «Чат с ИИ». Нажмите файл слева или «Файлы и код», чтобы вернуться к коду. При переключении сохраняются открытый файл и черновик. Терминал и ветка Git доступны в нижней строке. |
| Открывать выбранный диалог сразу в KodaForge | В поле «ID диалога для автооткрытия» укажите последний сегмент адреса диалога BB (начинается с `thr_`). При обычном открытии этого диалога из списка BB сразу покажет его редактор. Другие диалоги и ссылки на отдельные сообщения открываются как обычно. Пустое поле сохраняет ручной вход. |

Те же настройки доступны через CLI. Подставьте ID своего диалога во вторую команду.

```sh
bb plugin config kodaforge-inspector set enabled true
bb plugin config kodaforge-inspector set autoOpenThread 'thr_EXAMPLE'
bb plugin config kodaforge-inspector set autoOpen true
```

Чтобы отключить любую функцию, задайте её переключателю (`enabled` или `autoOpen`) значение `false`. ID можно сохранить для следующего включения.

## Установка на сервере BB

Нужны Node.js с npm, BB с поддержкой SDK из манифеста и KodaForge. Для новой установки основной редактор доступен в каталоге BB по имени `kodaforge@bb-community`. Выполните из корня checkout bb-config:

```sh
cd plugins/kodaforge-inspector
npm ci --include=dev
npm run typecheck
npm test
bb plugin build .
bb plugin install . --yes
bb kodaforge-inspector status
```

Перезагрузите страницу браузера и откройте редактор диалога. В выводе повторной команды `status` поле `browser` покажет время и результат последней проверки. До первого открытия редактора результат может отсутствовать.

## Обновление и возврат

BB проверяет обновления основного KodaForge из настроенного источника. Установить предложенную версию можно кнопкой Update или командой `bb plugin update kodaforge --yes`. Инспектор поставляется отдельно в bb-config. После обновления он проверяет видимую область редактора, признаки навигации, ветки и терминала. При включённом центральном чате инспектор применяет раскладку к совместимому интерфейсу. Если структура изменилась, инспектор снимает свой слой и показывает причину. Изменение экспериментального API BB может потребовать обновления самого инспектора.

Команда `bb kodaforge-inspector status` показывает установленный источник и результат последней проверки браузера. Поле `upstreamTracking` сверяет источник с записью KodaForge в конфигурации команды. Оно не определяет, установлена ли самая свежая версия.

Для возврата к штатному KodaForge выполните `bb plugin disable kodaforge-inspector` и обновите страницу. Чтобы снова включить инспектор с сохранёнными настройками, выполните `bb plugin enable kodaforge-inspector` и обновите страницу. Эти операции управляют только инспектором.
