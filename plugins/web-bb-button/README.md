# Web BB Button

Кнопка-глобус «Открыть BB в браузере» в левой вертикальной навигации, перед меню «Ещё». Открывает https://example.getbb.app в новой вкладке. Авторизации и токены не хранит.

Реализована content script без замены Navigation: добавляет собственную ссылку в существующую rail по атрибуту `data-nav-rail-item`. При смене навигации на Top list кнопка не показывается. При отключении и перезагрузке плагина observer и ссылка удаляются. После обновлений BB, меняющих разметку rail, проверьте селектор.

Восстановление: `npm ci --include=dev --ignore-scripts`, `bb plugin build .`, `bb plugin install . --yes` на машине сервера из каталога плагина.
