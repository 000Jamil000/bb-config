# Восстановление после потери сервера

1. Клонируйте этот репозиторий на доверенную машину.
2. Возьмите свою внешнюю копию зашифрованного архива личной конфигурации и ключ.
3. Восстановите `.local/config/` и `.local/docs/` по [инструкции](docs/server-backups.md).
4. Используйте личную инструкцию из `.local/docs/` для конкретных адресов и путей.
5. Для истории, машин и настроек самого BB нужен отдельный зашифрованный экспорт BB.
6. Проверьте план `python3 scripts/restore.py --plugins`, затем примените его на сервере.

Один GitHub восстанавливает код и обезличенные настройки. Личная часть,
авторизации, переписка и ключи в публичном репозитории отсутствуют.
